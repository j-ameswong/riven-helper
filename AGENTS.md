## On the warframe.market API

This project makes use of the public unauthenticated warframe.market API. The `bruno/{v1,v2}` directories provide useful endpoints. For the scope of this project, only the riven related ones will be used. Requests should include the following `User-Agent` header:

```User-Agent: RivenHelper/0.0.1 (+https://github.com/j-ameswong/riven-helper)```
